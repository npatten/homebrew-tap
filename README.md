# Homebrew Tap

Homebrew formulae for tools published by Nikko Patten.

## Clew

In Greek myth, Ariadne gave Theseus the "clew" (a ball of thread) to navigate the labyrinth so he could find his way back out. This Clew is built to help us navigate the twists and turns of our own projects.

There are endless ways to manage software projects, maybe this one suits you.

[Clew Github](https://github.com/npatten/Clew)

## Install

```bash
brew install npatten/tap/clew
```

#### Note:

The `Formula/clew.rb` file is generated and updated by Clew's release workflow. Do not edit it by hand unless release automation breaks.
